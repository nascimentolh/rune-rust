# Code of Conduct

We want Rune Rust to be a friendly place to learn and build.

- Be respectful and patient; assume good intent.
- Critique code, not people. Explain the why, and point to the reference when you can.
- No harassment, discrimination, personal attacks or sharing others' private information.
- Don't post game files, caches, keys, account details or anything you aren't entitled to share.

Maintainers may edit or remove comments, commits, issues and pull requests that break these
rules, and may block people who keep breaking them. To report a problem, open an issue or contact
a maintainer privately through their GitHub profile.

This code adapts the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).
